# Проверка проекта

Проверены HTTP-запросы к приложению через TestClient с изолированной SQLite-базой, используемой только в тестах:

- Полный цикл POST, GET одного пользователя, GET списка, PUT, DELETE.
- Отсутствующий пользователь: 404 для GET, PUT, DELETE.
- Повторяющийся email: 409 при создании и изменении, корректный rollback.
- Неверные данные: 422 для некорректного email, возраста, пустого имени и null при обновлении.
- Swagger /docs и ровно пять операций в OpenAPI.

Результат: 5 тестов успешно.

Подключение к установленному MS SQL Server из ограниченного окружения исполнителя проверить не удалось: Windows SSPI возвращает 0x8009030E, «В пакете безопасности отсутствуют учетные данные». Политика среды запрещает исполнителю запуск вне песочницы. Это не ошибка доверия к TLS-сертификату. Ранее предложенные скрипты изменения реестра не нужны и в архив не включены.

Рабочая конфигурация использует MS SQL Server на localhost и текущую Windows-учётную запись. Для реальной проверки SQL Server запускайте main.py или run.py напрямую в PyCharm/обычном пользовательском PowerShell.
